UMPK Campus Companion - lib folder

1. Apne Flutter project ka purana lib/ folder is lib/ se replace karein
   (pehle backup le len). pubspec.yaml ko haath na lagayein.
2. Agar test/widget_test.dart hai to usay delete kar dein.
3. Terminal mein chalayein:
   flutter pub get
   flutter analyze
   flutter run
Flutter 3.35 ya naya chahiye (RadioGroup ki wajah se).
